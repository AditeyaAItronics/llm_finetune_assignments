## Setup

| | |
|---|---|
| Model | GPT, d=256, 8 layers, 8 heads, context 512, tied embeddings, **19.3M params** |
| Data | TinyStories, GPT-2 BPE, 55M train / 1M val tokens |
| Optimizer | AdamW (0.9, 0.95), wd 0.1, cosine 1e-3 → 1e-4, grad clip 1.0 |
| Precision | fp16 autocast + GradScaler on T4 (bf16 on sm_80+) |

**Reversible variants.** Both keep two residual streams and can rebuild each layer's input from its output, so backward stores no per-layer activations:
- `euler`: two-stream coupling (RevNet/Reformer), `y1 = x1 + h·Attn(x2)`, `y2 = x2 + h·MLP(y1)`
- `midpoint`: leapfrog step, `(a, b) → (b, a + 2h·F(b))`, with `F` a full transformer block
